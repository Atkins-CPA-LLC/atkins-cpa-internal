# Internal Tools Documentation Maintenance

This repository stores support materials for Atkins CPA internal tools and
integrations. The current public-facing files are:

- `README.md` - Repository overview and links to legal documents.
- `EULA.md` - End User License Agreement for internal tools.
- `PRIVACY.md` - Privacy policy for internal tools.
- `LICENSE` - MIT license text.

## Review Checklist

When internal tooling changes, review the documentation for:

- QuickBooks Online API access and authorization language.
- Data categories collected from connected accounting systems.
- Data uses for financial analysis, forecasting, automation, and fractional CFO services.
- Data retention, deletion, and user rights language.
- Atkins CPA contact details and website references.

## Change Policy

Keep routine updates in `README.md`, `docs/**`, `EULA.md`, and `PRIVACY.md`.
Do not use documentation maintenance commits to change application behavior,
credentials, runtime configuration, dependencies, or integration code.
